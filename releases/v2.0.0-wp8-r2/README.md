# ML-CGS evidence maturity review: IJGGC V2 WP8-R2 archive

Version: 2.0.0  
Release date: 2026-07-31  
GitHub versioned archive: https://github.com/yqma7980/ml-cgs-evidence-maturity/tree/v2.0.0-wp8-r2/releases/v2.0.0-wp8-r2  
Persistent archive: https://doi.org/10.5281/zenodo.21644711

This archive contains the synchronized evidence products and deterministic
scripts supporting the IJGGC-oriented WP8-R2 manuscript.

## Evidence boundary

- Locked primary corpus: 70 full-text-verified primary ML-CGS records.
- Main quantitative universe: 57 claim-eligible records.
- Full independent-review matrix: 627 paper-field items.
- Decision basis: 139 exact agreements, 450 author-adjudicated disagreements,
  and 38 author-verified items for which the locked baseline was unavailable.
- Unknown, unclear, and not-reported values remain distinct from zero.
- No machine-proposed resolution was adopted without human verification.

## Contents

- `data/supplementary_tables`: Tables S1-S16 and raw update-search logs.
- `data/evidence`: synchronized R2 evidence tables used for the manuscript.
- `methods`: coding manuals and reference metadata overrides.
- `figures`: figure data, traceability, captions, and publication graphics.
- `tables`: manuscript table data and LaTeX exports.
- `scripts`: deterministic integration, figure, supplement, metadata, and
  validation scripts.
- `reports`: reference identity, metadata completion, reliability, and archive
  readiness reports.

No copyrighted article PDFs, internal reviewer workbooks, credentials, author
email addresses, or absolute local paths are included.
