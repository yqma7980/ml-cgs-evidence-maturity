# IJGGC V2 public archive readiness

## Status

LOCAL CANDIDATE READY AFTER BUILD; EXTERNAL DEPOSIT NOT YET CONFIRMED.

The release builder creates a public-safe candidate containing synchronized evidence tables, Supplementary Tables S1-S16, coding manuals, figure data, deterministic generation scripts, and SHA256 checksums.

The candidate excludes copyrighted full-text PDFs, private review workbooks, email addresses, and absolute local paths. Existing GitHub and Zenodo records are not modified by the build.

## Author-controlled external gate

Before journal submission, the author must:

1. inspect the local archive candidate;
2. publish the synchronized release to the intended GitHub repository;
3. create or update the Zenodo record;
4. verify that the DOI resolves publicly;
5. replace prospective wording in the manuscript and cover letter with the final release URL, version, and DOI; and
6. rebuild the submission PDF after those identifiers are inserted.

Until those steps are complete, the manuscript correctly states that the synchronized archive will be deposited and does not claim DOI-backed permanence.
