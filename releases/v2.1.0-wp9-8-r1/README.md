# ML-CGS evidence maturity archive, version 2.1.0

This version contains the author-verified WP9.8-R1 analysis tables, supplementary files, coding rules, figure data, figures, and deterministic generation scripts supporting the review entitled *From simulator emulation to storage decisions: A decision-centered review of evidence maturity in machine learning for geological CO2 storage*.

The release preserves a locked 70-record full-text-verified primary corpus and a 57-record quantitative universe. It includes 51 signed field decisions across 37 papers and nine signed method-family mappings. No copyrighted article PDF, confidential material, personal review correspondence, or internal signed workbook is included.

The versioned GitHub copy is available at <https://github.com/yqma7980/ml-cgs-evidence-maturity/tree/main/releases/v2.1.0-wp9-8-r1>. The permanent Zenodo DOI is added after publication of the new version.
