# Field-specific Wen source provenance

S9/S9a distinguish study registration, historical evaluated-document context and membership. The Wen rows now explicitly describe composite, field-specific evidence records rather than a single preprint standing for every adopted value.

S9b lists 27 analysis-relevant fields per Wen record: six typed indicator inputs, seven physical components, five scores and their states, and four decision/method mappings. Sixteen fields have prior exact approved formal-source addenda, whose identifiers, fingerprints, source-object hashes and locators are retained. The other 38 values are unchanged retained values with historical base context; this bounded correction does not retrospectively verify each one against the final journal text.

S9c identifies the source objects actually checked locally. A pipe-separated hash list in a composite source record denotes distinct objects, not a hash of one file. Formal-main and ESI evidence applies only within the approved field scopes in S9b. Missing supplements and unverified claim bridges are not assumed.

No scores, categories, main-membership flags or strict-subset flags change. Both Wen records remain outside the verified-journal sensitivity subset because a document-wide retained-claim bridge has not been established. Historical approval/source ledgers are preserved, including their earlier proposal-status columns; the application-current column and exact approved value define their later effective status.

The actual PDFs are not redistributed in the manuscript package. Filename, version, hash and locator allow the document used to be identified. Internal local path/readback evidence remains with the project audit.
